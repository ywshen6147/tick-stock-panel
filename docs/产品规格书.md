# TSP 产品规格书（Product Specification）

> 版本：v1.0（2026-09-07）
> 范围：A 股智能量化工作台 TSP（tick-stock-panel），含 vibe-astock 深度集成（B1 阶段 1 已完成）
> 说明：本文档面向产品/研发/测试，描述系统能力、架构、模块规格、接口与验收口径。仅供学习研究，不构成投资建议。

---

## 1. 产品定位

### 1.1 一句话定位

**自托管、零运维的 A 股「选股 + 监控 + 回测」量化工作台**——多数据源能力路由、分钟级策略执行、全时段异动监控、AI 辅助研究，单入口集成 vibe-astock 短线复盘引擎。

### 1.2 目标用户与场景

| 用户 | 场景 |
| :--- | :--- |
| 量化研究者 | 本地全 A 扫描选股、回测验证、因子挖掘 |
| 短线交易者 | 连板梯队、情绪周期、竞价/盘中/偏移异动监控、盘后 AI 复盘 |
| 二次开发者 | 数据源插件化接入、自定义策略/信号/扩展页面、AI 生成策略 |

### 1.3 明确不做（边界）

- 不对标同花顺 / 通达信等商业看盘软件
- 不内置「AI 荐股 / 涨停预测」
- 不构成投资建议，回测结果不代表未来收益
- vibe-astock 不作为独立导航存在，降级为「后台引擎」由 TSP 单入口承载

## 2. 总体架构

### 2.1 分层架构

```
┌─────────────────────────────────────────────────────────────┐
│  呈现层  React 18 · Vite · TS · Tailwind · ECharts          │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────────────┐  │
│  │ TSP 核心页面 │  │ vibe 页面    │  │ 扩展页面(动态菜单)   │  │
│  │ (18+)       │  │ (6 路由)     │  │ (第三方数据字段)     │  │
│  └─────────────┘  └─────────────┘  └─────────────────────┘  │
└──────────────┬──────────────────────────────────────────────┘
               │ HTTP / SSE（同源 /api）
┌──────────────▼──────────────────────────────────────────────┐
│  应用层  FastAPI · Pydantic v2 · APScheduler · sse-starlette │
│  认证中间件 → 能力路由 → REST/SSE → 监控引擎 → 任务调度 → 交易  │
│  日探针                                                            │
└──────────────┬──────────────────────────────────────────────┘
               │
┌──────────────▼──────────────────────────────────────────────┐
│  计算层  Polars（指标流水线/复权/信号）· 自研回测引擎          │
└──────────────┬──────────────────────────────────────────────┘
               │
┌──────────────▼──────────────────────────────────────────────┐
│  存储层  Parquet 分区表 · DuckDB · JSON 按日缓存             │
└──────────────┬──────────────────────────────────────────────┘
               │
┌──────────────▼──────────────────────────────────────────────┐
│  数据源层 插件化：TickFlow SDK · fuyao REST · stock-sdk      │
│            · YAML 自定义源 · vibe-astock(8910, 代理透传)      │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 关键机制

| 机制 | 说明 |
| :--- | :--- |
| **能力路由矩阵** | 各数据集（日K/除权/实时/分钟/盘口/财务）按源声明能力独立路由，注册表集中定义、可扩展；TickFlow 档位探测 + 插件源能力声明，fail-closed（未声明即拒） |
| **交易日探针** | fuyao 交易日历（确定性）→ tickflow 行情时间戳探针（OR 语义）→ 工作日兜底；节假日自动停实时轮询与分钟增量 |
| **财务多源合并** | 按 `(symbol, period_end)` 报告期累积，多源取并集、逐列按公告日取最新（PIT）；公告前一律空值，绝不填 0 |
| **分层缓存** | enriched 存储仅 15 列基础数据，读取时现算 68 列指标与信号 + 进程内快照缓存 |
| **回测执行隔离** | spawn worker 子进程运行，持久 run ID，刷新/切页重连不丢任务 |
| **认证中间件** | 未设密码：本机/内网放行、公网 403；已设密码：校验 session，无效 401 |

### 2.3 技术栈

| 层 | 选型 |
| :--- | :--- |
| 后端 | FastAPI · Pydantic v2 · APScheduler · sse-starlette |
| 数据 | Polars（计算）· DuckDB（查询）· Parquet（存储） |
| 回测 | 自研仓位模拟引擎（T+1/费用/滑点/分钟回放）· vectorbt（部分路径） |
| 数据源 | TickFlow SDK · fuyao（同花顺 REST）· stock-sdk（Node 插件）· YAML 自定义源 · vibe-astock |
| AI（可选） | OpenAI 兼容接口（DeepSeek/通义/Ollama 等） |
| 前端 | React 18 · Vite · TypeScript · Tailwind · Tanstack Query · Lightweight Charts · ECharts · dnd-kit |
| 部署 | Docker 两阶段构建，单容器；Dev 模式前后端分离（3011/3018） |

## 3. 模块规格

### 3.1 行情总览

#### 3.1.1 看板 Dashboard（`/`）
- 市场情绪评分 + 涨跌/成交额榜单
- 概念/行业领涨领跌（点击板块直达成分股，领涨股带涨跌幅）
- 大盘异动事件流，一日全貌

#### 3.1.2 自选 Watchlist（`/watchlist`）
- 自选股池，多分组管理（M:N），表格/卡片双视图
- 换手/量比/RSI 等实时指标，按档位分流实时刷新（Free 前 5 只 ≥6s / Starter+ 全市场）
- 实时行情列 price/pct/amount 使用 rt_ 回退

#### 3.1.3 指数 Indices（`/indices`）
- 沪深指数浏览与同步（610 指数，日 K 595 行）

### 3.2 选股与回测

#### 3.2.1 策略引擎（`/screener`）
- **25 个内置策略**，每策略独立 Python 文件，Polars 表达式向量化
- 类型：趋势/形态（趋势突破·均线多头·MA金叉·MACD金叉放量·布林突破·均线粘合突破·平台整理突破·放量创60日新高）/ 量价/涨停（量价齐升·高换手强势·连板股·断板反包·涨停动量·接近涨停·涨停基因活跃股）/ 反转/波动（超跌反弹·超卖反转·新低反转·低波动龙头·回踩MA20·回踩支撑·强势开盘·MACD零下回升·长下影反击·RSI中轴回踩）
- **分钟策略**与日线策略共用标的池，按策略声明周期自动路由
- **ETF 支持**：顶部切换股票/ETF，ETF 复用 `kline_etf_enriched`，仅开放技术类策略
- 扩展三种方式：①自定义信号（UI 字段+操作符+阈值，不写代码）②AI 生成（自然语言 → LLM → ast 安全校验 → `data/strategies/ai/`）③自定义编写（`data/strategies/custom/`）

#### 3.2.2 回测（`/backtest`）
| 模式 | 说明 |
| :--- | :--- |
| 因子回测 | IC/IR、分层收益、多空组合，62+ 因子目录先筛无效指标 |
| 策略回测 | 净值曲线、回撤、夏普、胜率，T+1/手续费/滑点/止损，SSE 流式进度 |
| 分钟策略回测 | 逐交易日回放信号、分钟收盘入场、分钟级成交明细 |
| 验证 | 参数敏感性与滚动样本外 |
- 结果导出 CSV（概要/净值/交易明细/分标的统计）→ 保存候选 → 一键载入复测
- ETF 支持：`asset_type=etf`，单次回测单一资产类型

#### 3.2.3 因子挖掘（`/mining`）
- 训练区间因子方向重估 + 相关性去重（Rank IC）+ 多因子排名组合搜索（≤4 因子）
- 嵌套样本外验证（inner/outer，purge 30 交易日 + embargo）
- T-1 市场环境，fail-closed；财务因子点时口径（公告次日起生效，绝不填 0）
- 候选入库，显式确认后才发布，**永不自动上线**；自动周度任务默认关闭
- 因子目录含 A 股实证维度：收益形态（彩票效应/偏度/上涨天数）、流动性（Amihud/换手异动）、涨停基因（连板计数）、财务（PB/ROE/毛利/净利率/营收/净利增速/负债率）

### 3.3 个股与板块分析

#### 3.3.1 个股分析（`/stock-analysis`，Beta）
- 专用日 K 图表：主图 + 成交量 + 滑块，默认近 6 个月
- **9 类关键价位**：压力支撑 · 成交密集区 · 枢轴点 · 前高前低 · Keltner 通道 · ATR 波动通道 · 缺口位 · 斐波那契 · 整数关口
- **AI 四维分析**：技术/基本面/财务/消息面流式生成（客观视角，不输出买卖建议）

#### 3.3.2 财务分析（`/financials`）
- 利润表/资负表/现金流/关键指标，多源并集合并（fuyao 财务四表适配）+ AI 解读

#### 3.3.3 概念/行业分析（`/concept-analysis`、`/industry-analysis`）
- ths 维度涨幅轮动矩阵 + 领涨/领跌主线 + 个股穿透

#### 3.3.4 市场环境（`/regime`）
- **5 档环境 state**：强势/偏强/震荡/偏弱/弱势（日频打分）
- **情绪周期 6 阶段 phase**：冰点/启动/主升/高潮/退潮/修复，由连板梯队（高度、宽度、晋级率、梯队完整度）驱动，EMA 平滑 + 2 日确认，平均段长约 9.7 天
- **主线识别**：概念/行业涨停梯队聚合排名（0.35*涨停数+0.25*最高板+0.25*梯队档位数+0.15*二板宽度），top30 每日持久化
- 宽基/风格标签过滤（成员数上下限 + 黑名单）

#### 3.3.5 连板梯队（`/limit-ladder`）
- 连板层级统计 + 概念/行业分布 + 封单监控（可切换连跌梯队）

### 3.4 监控与复盘

#### 3.4.1 监控中心（`/monitor`）
- 四类监控规则：策略监控 / 个股信号监控 / 价格涨跌监控 / 全市场异动
- 多条件 AND/OR + 冷却期去重 + 严重级别（info/warn/critical）
- 命中弹窗（可配声效）+ 持久化 `alerts.jsonl` + 菜单未读徽标
- 触发记录详情：展示命中条件与当前价位
- 飞书 Webhook 推送（支持签名校验）

#### 3.4.2 异动监控（`/abnormal-moves`）
| Tab | 口径 |
| :--- | :--- |
| 竞价异动 | fuyao 同花顺盘前风向标（5-6 只/日，含竞价涨幅/概念标签）+ 当日/次日真实收益对照 + 追高风险标记（高开≥5% 追高当日均值显著为负，60 日回测） |
| 盘中异动 | 涨停/炸板/翘板/跌停/新高/新低/放量当日信号聚合，零新增采集 |
| 偏移异动 | 交易所偏离值口径：主板 3 日 ±20%、创业板/科创板 ±30%、北交所 ±40%；10 日 +100%/−50%、30 日 +200%/−70%，实时接近度（≥100% 触发/≥70% 边缘/≥50% 观察） |

#### 3.4.3 复盘（`/review`，Beta）
- 盘后 AI 自动生成市场复盘，注入龙虎榜资金动向 + 盘前风向标对照
- 定时执行、推送飞书、下载 Markdown

## 4. 数据与扩展

### 4.1 数据源插件化

| 数据源 | 说明 |
| :--- | :--- |
| TickFlow | 官方 SDK（日K/分钟K/指数/财务/实时行情），档位 None/Free/Starter/Pro/Expert |
| fuyao | 同花顺 REST（行情/财务/龙虎榜/盘前风向标/交易日历） |
| stock-sdk | Node 插件示例（Docker 镜像内置） |
| YAML 自定义源 | 声明自有 HTTP 接口 |
| vibe-astock | 8910 独立服务，通过后端代理接入 |

### 4.2 能力路由矩阵

- 数据集：日K / 除权因子 / 实时行情 / 分钟K / 五档盘口 / 财务 / 全量分钟（full_minute）
- 档位能力：
  - Free：自选前 5 个实时监控（≥6s）
  - Starter+：全市场实时行情
  - Pro：分钟K + 盘口
  - Expert：WebSocket + 财务 + 全量分钟
- UI 提示以「能力名」表达，不依赖 TickFlow 档位名

### 4.3 全量分钟（full_minute）

- 独立能力，可路由；盘中将全市场当日 1 分钟 K 持续增量落盘 `data/kline_minute/`
- 冷启动自动全天修复轮；稳态增量轮（默认 6s，可配 3-120s）
- 仅连续竞价时段运行（9:30-11:30 / 13:00-15:00），午休/收盘自动暂停恢复
- `unique(symbol, datetime)` 幂等合并，与盘后分钟同步互不冲突

### 4.4 数据同步与管道

- **盘后定时管道**：APScheduler 15:30 CST 自动：拉日 K → 重算 enriched → 跑监控规则
- **历史扩展**：数据页手动触发向前补历史（日K + 除权因子 + 全量 enriched 重算）
- **数据完整性自检**：启动 30s 后后台扫描停机缺口，自动创建修复任务
- **实时行情与数据同步互斥**：数据同步运行期间实时行情临时暂停（409），防除权因子与行情写入冲突

### 4.5 第三方数据接入

- HTTP 定时拉取（Tushare 等）· CSV/Excel 上传 · JSON 写入
- 自动 schema 发现 + 符号归一，并入 DuckDB 同台分析
- 扩展字段配成一级页面（动态菜单），即配即用

## 7. 配置规格

### 7.1 核心配置（`.env`）

```ini
TICKFLOW_API_KEY=     # 留空 = None 模式（历史日K免费）；填 Key 解锁档位能力
AI_PROVIDER=openai_compat   # openai_compat | ollama
AI_BASE_URL=          # OpenAI 兼容地址
AI_API_KEY=           # 留空 = 关闭 AI
AI_MODEL=             # 如 deepseek-chat
HOST=0.0.0.0
PORT=3018
LOG_LEVEL=INFO
DATA_DIR=./data
AUTH_PASSWORD=        # 公网部署预置密码
BACKEND_EXTRAS=       # legacy-cpu 兼容老 CPU
```

### 7.2 配置优先级

1. 面板设置页（UI 修改立即生效，持久化到 `data/`）
2. `.env` 文件（启动时读取）
3. 环境变量（优先级最高）

### 7.3 常用设置项（面板）

- 凭据与能力（重新检测档位标签、能力路由矩阵）
- 数据源（TickFlow/fuyao/自定义源切换、各数据集路由）
- AI 接口（Provider/Base URL/Key/Model/每日 Token 预算）
- 实时监控（实时行情开关、自选作用域、分钟刷新间隔、推送渠道）
- 扩展页面（第三方字段配成一级菜单）
- 信号库 / 菜单 / 系统设置
